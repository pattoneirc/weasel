# AI 创作者词库测试包

这是配置测试包，不会替换、卸载或重新注册你当前的小狼毫程序。它会临时修改当前用户的 Rime 配置，并在修改前自动备份。

## 使用步骤

1. 把整个压缩包解压到 D 盘，例如 `D:\AI_Rime_Test`。
2. 双击 `测试安装配置.cmd`，确认后等待小狼毫重新部署。
3. 保持中文模式，测试：
   - 按 `Shift+2`，`@` 应直接上屏。
   - 输入 `github`，候选中应出现 `GitHub`。
   - 输入 `comfyui`，候选中应出现 `ComfyUI`。
   - 输入 `ue5`，候选中应出现 `Unreal Engine 5`。
4. 测试期间不要移动或删除本文件夹及其中的 `_backups`。
5. 测试结束后双击 `恢复原配置.cmd`。

## 安全边界

- 不修改小狼毫安装目录和程序文件。
- 不修改 Windows 输入法注册信息。
- 只写入当前用户的 `%APPDATA%\Rime` 配置目录。
- 备份默认保存在测试包旁边的 `_backups`，避免占用大量 C 盘空间。
- 检测到尚未恢复的测试配置时，会拒绝重复安装，防止覆盖恢复记录。

如果安装或恢复窗口显示错误，请不要删除测试包和 `_backups`，先保留错误信息。

启动器会显示确认和完成对话框。若操作失败，测试包目录会生成 `install-test.log` 或 `restore-test.log`；如果只看到黑框闪过，请先确认不是直接在 ZIP 压缩包中运行。
